# Textora 1.4.0 (5.1) - тестовая проверка дизайна

Дата: 11 ноября 2026. Публичный релиз не опубликован. Установленная копия Textora и корневой Textora.dmg не заменялись.

## Что изменилось

| Место | Поведение |
| --- | --- |
| Settings | Sidebar: General, Writing, Dictation, Shortcuts, Recent Results, About & Updates. Внутри General, Writing и Dictation отдельные вкладки. Прокрутка только текущей страницы. |
| My Style | Settings → Writing → My Style. Общий выключатель, область применения, профиль по умолчанию, назначения приложениям и редактируемые профили. |
| Редактор профиля | Preferences и Preview. Параметры сохраняются по Save; создание профиля не включает стиль и не меняет назначения. |
| Описание | Необязательный импорт: Suggest settings → Apply suggestion или Discard. Сохранённая заметка не становится инструкцией модели. |
| Предпросмотр | Одна Generate preview, выбор действия, Before / After, пометка Illustration до запроса. Без AI ручные параметры доступны; причина недоступности генерации объясняется. |
| Меню Textora | Отдельные My Style и What’s New удалены. История, Settings и проверка обновлений остаются. |
| Обновление | Версия берётся из bundle. Содержимое находится в Resources/ReleaseNotes.md. Обзор показывается один раз для новой пользовательской версии; повторное открытие в About & Updates. |
| Выпуск с исправлениями | Компактное окно 680×460 с разделом Fixed, без настройки старых функций. Несовпадающая версия описания не показывает старый обзор. |

Визуальная основа - системные SwiftUI/AppKit GroupBox, Form, picker, поля и разделители. Сохранены иконка Textora, акцент и привычные панели. Проверены светлая и тёмная темы, минимум Settings 840×600, длинное имя профиля и отсутствие AI.

## Почему остаются Fix, Shorten, Formal и Humanize

Операция определяет действие, профиль добавляет предпочтения. В коде они совместимы: Fix ограничен минимальными исправлениями, Formal остаётся профессиональным. Язык операции, смысл, имена и форматирование важнее пожеланий стиля. Кнопки не являются альтернативами профилю.

| Сценарий | Ожидаемое действие |
| --- | --- |
| Personal + Fix | Исправить ошибки, не переписывать текст ради дружелюбного тона. |
| Personal + Formal | Сделать сообщение профессиональным; сохранить термины и допустимые настройки написания. |
| Work + Humanize | Сделать фразу естественнее с профессиональными предпочтениями профиля. |
| By app: Slack → Work, Telegram → No style | В Slack применять Work; в Telegram использовать обычные операции без профиля. |
| My Style Off | Обычные операции работают, профили и назначения сохраняются. |

Пример в Preview: Before: “Hi Rob, I am going to be a little late, I will finish the task tomorrow morning.” After / Illustration: “Hi Rob, I’m running a little late. I’ll finish the task tomorrow morning.” Это иллюстрация, не ответ живого провайдера в этой проверке. Generate preview отдельно отправляет пример выбранному провайдеру.

## Исправленные зависимости

- Переход к My Style из панели сохраняет первоначальное поле назначения.
- При редактировании стиля отменяются отложенные чтения выделения и перехват Return, результат остаётся доступен после закрытия. Автоматической вставки при закрытии нет.
- Параметры AI сохраняются перед сменой страницы и повторным открытием Settings.
- Переход из onboarding в Settings не оставляет мастер поверх редактора; возврат сохраняет шаг.
- Смена действия или параметров отменяет устаревший тест профиля; поздний ответ не заменяет новый.
- При переходе к настройке AI несохранённый профиль можно сохранить, отбросить или остаться в редакторе.
- Убраны дублирующие Save settings и Save dictation preferences. Неработавший переключатель коротких тире заменён пояснением общего правила.
- Закрытые установленные приложения показывают имена, а не bundle ID.

## Ограничения приёмки

Computer Use при попытке открыть подписанную сборку сообщил `Computer Use permissions are not granted`. Поэтому интерактивный проход по приложению, живые ответы AI, микрофон и вставка в Slack/Telegram/Gmail в этой проверке не подтверждены. Снимки получены нативным тестовым рендерингом SwiftUI/AppKit, а не нарисованы как макеты.

В коротком окне нижние секции Form требуют прокрутки. В Preview без провайдера кнопка настройки AI расположена ниже примера. Список сохраняемых терминов разделяется запятыми; отдельная запятая внутри одного термина этим интерфейсом не поддерживается.

Тестовая сборка подписана существующим Developer ID; отдельная отправка этого кандидата на нотариализацию и публикация GitHub Release не выполнялись. На новую версию нельзя переносить описание старой автоматически: при несовпадении версии окно намеренно предлагает ссылку на историю вместо устаревшей информации.
