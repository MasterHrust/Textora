# Textora 1.4.0 (5.2) - запись, перевод и Slack

Дата: 11 ноября 2026. Это локальная тестовая сборка. Установленная Textora, корневой Textora.dmg и GitHub Release не заменяются.

## Что мешало работе

Ошибка «Place the cursor in an editable text field» возникала до запроса микрофона: Textora не получала подтверждённый редактируемый AX-элемент. В старом пути успешный системный запрос фокуса мог вернуть контейнер, после чего фокус на уровне приложения или окна уже не проверялся. Это соответствует классу проблем Electron/Slack, но конкретное состояние живого Slack в этой проверке не наблюдалось.

Меню результата использовало вложенный Menu → Picker. Частые изменения уровня звука и таймера публиковались в родительской модели панели. Кроме того, выбор управления мог активировать Textora, а обработчик смены приложения завершал запись и скрывал панель. Неактивируемые панели не допускали клавиатурного фокуса для управления языками.

## Новое поведение

1. По умолчанию одно нажатие хоткея запускает запись. Клавиши можно отпустить. Повторное нажатие или Stop завершает запись. Settings → Shortcuts сохраняет отдельный вариант Hold to record.
2. Во время подготовки видны Preparing и Cancel. После запуска микрофона - Listening, время и Stop. Поздний ответ разрешения или старой сессии не должен возобновлять отменённую запись.
3. Text и Message выбираются непосредственно на панели, без вложенного меню. Выбор действует для текущей записи, если сделан до Stop, и сохраняется для следующих.
4. Рядом видно Translate: Off или языки перевода. Раскрытие показывает Translate after recording, From / Auto-detect, To и Swap. При Auto-detect Swap недоступен, чтобы Auto не становился целевым языком.
5. Аудиоиндикатор и таймер обновляются отдельно от управления; окно не пересоздаётся и не перепозиционируется на каждом изменении уровня звука.
6. Использование панели и смена приложения не останавливают запись. Поле назначения остаётся первоначальным; автоматическая вставка заново проверяет именно его. При смене поля готовый текст остаётся для копирования.
7. Stop завершает прослушивание и убирает его управление. Затем идёт распознавание/перевод; Text вставляется при подтверждённом поле, Message всегда открывает предпросмотр.

## Как обрабатывается неподтверждённое поле

Распознавание фокуса проверяет только объявленные AXFocusedUIElement-ссылки и предков, включая фокус приложения/окна. Есть общий лимит обхода, защита от циклов и проверка PID. Чужие редакторы на странице не сканируются. Проверки защищённых полей, разрешений, read-only и назначения вставки сохранены.

Если после ограниченных попыток поле не удалось подтвердить, но исходное приложение разрешено и не является защищённым контекстом, доступна диктовка для копирования. В панели явно указано Copy only - field unavailable. Text показывает результат с Copy без неработающей Retry Insert. В Message доступны черновик и Copy, а Insert не предлагается без подтверждённого поля. Ошибка перевода сохраняет исходник и Retry Translation.

Буфер обмена заполняется при явном Copy. Не утверждается, что текст уже скопирован, пока пользователь не нажал кнопку. История по-прежнему работает только после включения.

## Примеры

| Задача | Действия |
| --- | --- |
| Просто надиктовать | Хоткей → Text → Translate: Off → говорить → Stop. |
| Говорить по-русски, получить английский | Text → раскрыть перевод → включить → From Russian / To English → Stop. |
| Автоматически определить исходный язык | From Auto-detect → выбрать To. Язык распознавания определяется локально, исходный язык не навязывается AI-переводу. |
| Подготовить сообщение | Message → при необходимости перевод → Stop → отредактировать Draft → Insert или Copy. |
| Приложение не раскрывает поле | Запись с пометкой Copy only → Stop → Copy → вставить вручную в выбранное поле. |
| Привычное удержание | Settings → Shortcuts → Hold to record. Режим фиксируется на начало записи. |

## Границы проверки

По просьбе пользователя доступ к Slack не использовался. Поэтому устранённые причины подтверждены кодом и тестами, а успешная автоматическая вставка в конкретной установленной Slack не заявляется. Если её AX-поле по-прежнему недоступно, результат можно получить через Copy only.

Локальная модель распознаёт 25 поддерживаемых языков автоматически. Выбор From является подсказкой для последующего AI-перевода и не добавляет модели поддержку других языков. Message и перевод требуют настроенного AI-провайдера; аудио остаётся локальным.

Тестовая сборка предназначена для локальной проверки. Публичная публикация и отдельная нотариализация этого кандидата не выполнялись.
