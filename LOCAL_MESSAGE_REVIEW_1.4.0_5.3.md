# Textora 1.4.0 (5.3) - локальный Message без перевода

Дата: 11 ноября 2026.

## Причина

В сборке 5.2 результат Message всегда переходил в composeMessage, даже с выключенным переводом. Аудио распознавалось локально, после чего текст расшифровки отправлялся настроенному AI-провайдеру для подготовки сообщения. Выключение Translate отключало смену языка, но не облачное составление сообщения. Это добавляло отдельное ожидание AI; длительность локальной загрузки модели и распознавания в этой проверке не измерялась.

## Исправленное поведение

| Выбор | Обработка |
| --- | --- |
| Text + Translate Off | Локальная расшифровка, без AI. |
| Message + Translate Off | Локальная расшифровка сразу становится редактируемым черновиком. Без AI и без ключа провайдера. |
| Translate On | AI-перевод; для Message составление и перевод выполняются одним запросом. |
| Improve with AI | Отдельное явное действие: отправить расшифровку и выбранные параметры стиля провайдеру. |

При Local draft полный личный стиль не применяется автоматически. Выполняются только локальные правила, включая короткие тире. Профиль в окне помечен как optional AI style. Облачный результат помечен AI draft, ожидание - Preparing with AI. После ошибки явного AI-запроса локальный черновик остаётся доступен; интерфейс не выдаёт такой запрос за отсутствие облачной обработки.

В истории локальный черновик не помечается как результат применения AI-профиля. Исходная расшифровка сохраняется отдельно от редактируемого текста. Поздний AI-ответ не заменяет более новый локальный черновик. При новом исходнике старый черновик очищается, пока ожидается AI, чтобы нельзя было скопировать результат от другой записи.

## Проверка

- Полный прогон Xcode: **199 тестов, 0 ошибок**, `/private/tmp/textora-message-53-acceptance.log`.
- Шесть новых проверок модели: AI-замыкание не вызывается локально; busy не включается; Unicode, пробелы, код, URL и почта сохраняются; явный запрос вызывается один раз; ошибка оставляет локальный текст; поздние ответы и новая расшифровка защищены от старого результата.
- Вызовы подготовки сообщения в контроллере требуют явного useAI. Автоматический вызов использует состояние перевода, повторная AI-подготовка доступна только по отдельной кнопке.
- Обычный Text проверен по коду: при выключенном переводе возврат происходит до конфигурации провайдера и AIClient. Профили и история сами по себе сетевого запроса не запускают.
- **32 нативных PNG**: светлая/тёмная темы, локальный Message без ключа и с доступным AI, явный AI-запрос, AI draft, ошибка AI с сохранением локального текста, панель записи и остальные варианты диктовки. Снимки содержат тестовые данные, не живые ответы провайдера.

Реальные AI-запросы, микрофон и данные Slack в тестах не использовались. Проверка не является измерением скорости распознавания на устройстве пользователя. Офлайн-модель всё ещё требует времени на загрузку и распознавание; устранён дополнительный автоматический AI-этап при Translate Off.

Установленная версия, корневой Textora.dmg и GitHub Release не заменялись. Публичная публикация и отдельная нотариализация кандидата не выполнялись.

Универсальный Release 1.4.0 (5.3) собран; `codesign --verify --deep --strict` вне песочницы прошёл. ZIP проверен по целостности, версии и встроенному описанию релиза. Лог: `/private/tmp/textora-message-53-release.log`.
